# Arrendi

PWA para que un arrendador pequeño genere sus cuentas de cobro cada mes, las envíe por correo y sepa quién le debe.

- **API:** FastAPI (Python), en `apps/api/`.
- **Web:** Next.js (TypeScript), en `apps/web/`.
- **Datos:** PostgreSQL, acceso y archivos en Supabase.
- **Monorepo:** Turborepo con pnpm.
- **Despliegue:** Vercel.

## Empezar

Lee `docs/primer-encargo.md`.
