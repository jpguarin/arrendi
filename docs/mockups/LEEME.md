# Mockups

Marcado de las diez pantallas diseñadas, exportado del editor de diseño.

Estos archivos no se abren solos en un navegador: dependen del editor. Lo útil es el HTML con estilos en línea que hay dentro de la etiqueta `<x-dc>`, que muestra la estructura, las medidas, los colores y los textos de cada pantalla.

| Archivo | Pantalla |
| --- | --- |
| `Main.dc.html` | Inicio |
| `Cuentas.dc.html` | Listado de cuentas |
| `Cuenta.dc.html` | Detalle de cuenta |
| `Pago.dc.html` | Registrar pago |
| `Inmuebles.dc.html` | Inmuebles y unidades |
| `Contrato.dc.html` | Contrato |
| `Ajustes.dc.html` | Configuración |
| `Alta1.dc.html` | Alta guiada: inmueble |
| `Alta2.dc.html` | Alta guiada: unidades |
| `Alta3.dc.html` | Alta guiada: primer contrato |

Los nombres, valores y fechas son datos de ejemplo. Las diferencias entre los mockups y lo que se construye están en `docs/diseno.md`.
